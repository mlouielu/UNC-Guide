應每日隨身攜帶文件
==============

根據美國法律規定[^1][^2][^3][^4]，外國人須隨時攜帶外國人登記文件[^5]。以下為應每日隨身攜帶之文件:


|簽證類別| I-20 | DS-2019 | EAD | I-94 | GC |
|--------|------|---------|-----|------|----|
| F-1    |  ✅   |         |     |  ✅   | |
| F-1 OPT|  ✅   |         |  ✅  |  ✅  | |
| J-1    |      |   ✅     |     |  ✅   | |
| H-1B,O-1|     |         |   |  ✅ | |
| F-2 | ✅ | | | ✅ | |
| J-2 | | ✅ | ✅ (如果有) | ✅ | |
| H-4| | | ✅ (如果有) | ✅ | |
| TN, TD | | | | ✅ | |
| LPR (綠卡) | | | | | ✅ (正本) |


文件
----

### I-94

* 至 I-94 網站列印: https://i94.cbp.dhs.gov/home
* 每月底過期，須每月重新影印
* 可於[學校印表機列印](https://edtech.unc.edu/service/carolina-print-hub/) (隱私考慮上建議不要)
* 隨時攜帶正本

### I-20

* 請參閱 [申請 I-20 或 DS-2019 表格](../getting-start/request-certificate-of-eligibility.md)
* 隨時攜帶正本
