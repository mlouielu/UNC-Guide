旅行相關
========

持 F-1 簽證或 J-1 簽證(F/J簽證)的人，在美國離境/出國前，都應先透過 ISSS 取得旅遊同意 (Travel Endorsement)。該簽名核准後會出現在 I-20 第二頁或是 DS-2019 第一頁，每次效期為一年或至學程結束。

旅行簽名申請
------------

目前以改用線上申請，步驟如下:

1. 使用 Onyen 登入 [ISSS Portal](https://isssportal.unc.edu/): https://isssportal.unc.edu/
2. 左側選單選擇 [General Student Services](https://isssportal.unc.edu/istart/controllers/client/ClientEngine.cfm?serviceid=CategoryServiceProvider&index=CE101)
3. Tasks 選擇 Travel Signature Request for ..., 並且完成表單後送出

表單送出後，過幾個工作日會請查收信箱信件，會將新的 I-20/DS-2019 寄送至信箱。收到新表格後請列印並簽名。


旅行證件
--------

再入境美國時，應準備:

1. I-20/DS-2019 以及效期內之旅行簽名
2. 有效 F-1/J-1 簽證
3. 超過六個月有效期之護照
