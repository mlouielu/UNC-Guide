建立 Onyen 帳號
===============

Onyen 是 *Only name you'll ever need* 的縮寫，學校中的各種數位服務都會使用這個帳號來管理。

請先建立你的 Onyen 帳號後，再設定你的 email。

請參考 [Creating an Onyen](https://tdx.unc.edu/TDClient/33/Portal/KB/ArticleDet?ID=188) 來建立 Onyen 帳號。
